# PLAYWRIGHT STAGE 2 REPORT

## 1. 작업 개요

- 단계: 2단계 대시보드
- 방식: 실제 Vue 화면 + 실제 FastAPI + 별도 SQLite 테스트 DB
- API Mock: 사용하지 않음
- 운영 DB: 사용하지 않음
- GPT 기능: 실행 및 결과 검증 제외

## 2. 테스트 데이터

전용 DB를 매 실행마다 재생성한 뒤 다음 데이터를 입력한다.

| 데이터 | 개수 |
|---|---:|
| 종목 / 보유현황 | 6 |
| 거래 | 6 |
| 뉴스 | 6 |
| 메모 | 6 |
| 태그 | 2 |
| 태그 연결 | 4 |
| 가격 알림 | 1 |
| 가격 알림 이력 | 1 |
| 성공 작업 로그 | 1 |

6개 데이터를 사용해 화면과 API가 상위 또는 최근 5개만 반환하는지 확인한다.

## 5. 실행 중 발견 및 조치 사항

### KPI 선택자 정확도

- 첫 실행: 전체 10개 중 9개 통과, 1개 실패
- 원인: `평가 손익` 문자열이 `평가 손익률`에도 부분 일치함
- 화면 값과 API 집계는 정상이었음
- Playwright 선택자를 정확한 라벨 일치 방식으로 수정
- 수정 후 대시보드 4개 및 전체 10개 테스트 통과
